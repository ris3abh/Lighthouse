# Agent guide for this Lighthouse workspace

This directory is a private immigration-case workspace managed by
[Lighthouse](https://github.com/rishabhsharma/lighthouse) (`lighthouse-gc`). It is the single source of
truth for the case. Read this before changing anything.

## Rules

1. **Human-in-the-loop for evidence.** Never add to `data/exhibits.json` or `evidence/` directly. Propose
   evidence by adding a candidate to `data/inbox.json` (status `pending`); the user accepts it in the Inbox.
2. **Validate every write.** Each `data/*.json` file has a JSON Schema in `.lighthouse/schemas/`. Run
   `lighthouse-gc validate` after editing.
3. **Never write secrets** (tokens, passwords, salary figures you weren't asked to record) into any file.
   Tokens live in the OS keychain.
4. **Don't edit generated files.** `DASHBOARD.md` and `data/criteria.json` are regenerated by
   `lighthouse-gc run dashboard`.
5. **Not legal advice.** Any judgment you write ("how a reviewer would see this") is an opinion and must be
   labeled as one.

## Layout

| Path | What |
|---|---|
| `lighthouse.yaml` | profile (`o1a` / `eb1a`), schedules, criterion overrides. No secrets. |
| `data/person.json` | who the case is for |
| `data/sources.json` | connected sources and tracked items |
| `data/inbox.json` | candidates awaiting the user's decision |
| `data/exhibits.json` | accepted evidence, each mapped to a criterion and a file in `evidence/` |
| `data/criteria.json` | computed scoreboard (generated) |
| `data/metrics.csv` | `date,source,item,metric,value` snapshots |
| `data/pipeline.json`, `letters.json`, `deadlines.json`, `opportunities.json` | in-flight work |
| `evidence/<criterion>/` | exhibit files named `<crit>_<yyyy-mm-dd>_<slug>.<ext>` |
| `drafts/letters/` | recommendation letter drafts |

## Useful commands

```sh
lighthouse-gc up                      # dashboard at http://127.0.0.1:7777
lighthouse-gc import <url>            # add a GitHub / Hugging Face source
lighthouse-gc run sync                # refresh sources, new candidates -> Inbox
lighthouse-gc run metrics-snapshot    # append today's metrics to data/metrics.csv
lighthouse-gc run dashboard           # re-score and regenerate DASHBOARD.md
lighthouse-gc validate                # check every file against its schema
```
