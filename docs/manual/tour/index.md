# Guided tour

One page per screen of the dashboard, in the order of the sidebar. The screenshots come from a fictional
filming workspace ("Maya Chen", a software engineer); nothing in them is real.

Every page reads and writes plain files in your workspace, so anything you see here is also a file you can
open, back up or hand to an agent.

| Page | What it's for |
|---|---|
| [Overview](overview.md) | Where you stand: criteria banked, what to do this week, next deadlines |
| [Inbox](inbox.md) | Proposed evidence and trackers waiting for your decision |
| [Evidence](evidence.md) | Accepted exhibits per criterion, what each still needs, preflight and the review packet |
| [Final merits](merits.md) | The evidence as a whole: by year, and by theme against rules you can read |
| [Metrics](metrics.md) | Dated snapshots of stars, downloads, citations and more |
| [Pipeline](pipeline.md) | In-flight work: ideas, applications, things you're waiting on |
| [Letters](letters.md) | Recommendation letter writers and drafts |
| [Contacts and Mail](contacts.md) | People you work with, follow-ups, and your case mail |
| [Calendar](calendar.md) | Deadlines and follow-ups, also as a calendar feed |
| [Agent](agent.md) | Every agent run, what it read, proposed and cost; missions |
| [Knowledge](knowledge.md) | The official sources every rule statement is checked against |
| [Memory](memory.md) | Everything Area O1 knows, as a sky of claims |
| [Sources](sources.md) | Connected accounts and chat-history imports |
| [Settings](settings.md) | Your AI, Gmail, missions, notifications, workspace |

Two controls sit on every page: **Visitor mode (O-1A) / Resident mode (EB-1A)** in the header switches the
criteria profile (your evidence is re-scored, nothing is lost), and **Ask** opens the chat panel.
