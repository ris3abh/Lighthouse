# 3. Product first, research second

Date: 2026-10-06 · Status: accepted

## Context
The spec frames Lighthouse as evidence-grounded memory for agents, with a knowledge vault and an evaluation
harness. Those only matter if people actually use the tool.

## Decision
Within each phase, user-facing product work comes first: importing Claude / ChatGPT sessions, dropping in
evidence, trackers and notifications. Research and experimentation (vault rigor, eval harness, ablations)
follow once the product is solid. The data model is still designed for the research track from day one
(SPEC 11a).
